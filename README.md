# Автотест на получение заказа по треку заказа в сервисе Яндекс Самокат с помощью API Яндекс Самокат
Шаги автотеста:
- Выполнение запроса на создание заказа.
- Сохранение номера трека заказа.
- выполнение запроса на получение заказа по треку заказа.
- проверка, что код ответа равен 200.

Файл data.py содержит тела POST и GET запросов
Файл configurstion.py содержит URL и пути запросов
Файл test_get_order_by_track.py содержит:
    - POST-запрос на создание нового заказа
    - GET-запрос на получение заказа по его номеру
    - автотест с проверкой, что возвращается код ответа 200

Для запуска тестов должны быть установлены пакеты pytest и requests
Перед запуском тестов необходимо добавить адрес тестового сервера в файл configuration.py -> URL_SERVICE = "адрес тестового сервера"
